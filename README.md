# Penske (penske)

A diversified transportation services conglomerate operating truck leasing, logistics, automotive retail, and professional motorsports across North America. Penske Corporation spans Penske Truck Leasing, Penske Logistics, Penske Automotive Group, and Team Penske with 73,000+ employees and approximately $43B+ in consolidated revenue. Customer self-service is delivered through web and mobile portals (Penske Fleet Insight, Penske Truck Leasing app, Penske Truck Rental); Penske does not publish a public developer API or partner integration portal.
